Every kind of Home tile can now show a picture: behind it, above it or beside it.

## For staff
Changed: The Outreach day, This week, Sunday bulletin, Notifications and Latest sermon tiles now have Picture behind, Picture above and Picture beside layouts, like Link tiles. Choose a picture and Best for this size uses it straight away; the tile's live content (the next thing on, how many are unread, this Sunday's theme) sits over a shade so it stays easy to read. The Outreach picture you could choose before but never see now shows.
Where: Admin panel → Drafts → your draft → Home screen → a tile → Picture, then Layout at this size.
Try: Give the This week tile a photo from a Sunday and choose Picture behind; try it in the phone preview's light and dark.
