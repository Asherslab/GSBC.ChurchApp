Staff can make a sign-in code so Apple's reviewers can try the app with a demo account, no passkey needed.

## For staff
Changed: App review in the admin panel makes a demo account and sign-in codes for it. A code works for 30 days unless you change it, can be used by several reviewers, and can be turned off at any time. A new code has a Copy button, since it's shown only once. On the phone, the Account screen has a quiet "App reviewer? Sign in with a code" link under the sign-in options.
Where: Admin panel → The app → App review (needs the Account manager role). On the phone: More → Account, when signed out.
Try: In App review, make a demo account, then make a code and copy it. On the phone, sign out, tap "App reviewer? Sign in with a code", and enter the demo account's email and the code. You're signed in, and Account doesn't offer to add a passkey. Turn the code off in the admin panel and the phone is signed out.
