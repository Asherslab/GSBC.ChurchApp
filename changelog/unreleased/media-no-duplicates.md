Uploading a picture or PDF the library already has offers the one it has, so the library keeps one copy.

## For staff
Changed: When you upload a file that's exactly the same as one already in Media, the upload says so and shows the one it has: its name, its folder and how often it's used. Use the existing one (the usual choice), or add it again anyway if you really want a second entry. If the check misses it, the library still notices when the upload finishes, uses the file it has and says so. Files private to a group are only matched for people in that group.
Where: Admin panel → Media → Upload, and the Upload button wherever you choose a picture (Home tiles, settings, rich text).
Try: Upload a picture, then upload the same picture again. Choose Use the existing one and see it selected where it already was. Try again and choose Add it again anyway: you get a second entry, and deleting one keeps the other working.
