A sign-in code adds its own capitals and dash as you type, and a code still works if setting up the passkey fails the first time.

## For staff
Changed: The code fields on Sign in (a parent's code, and an app reviewer's code) turn what's typed to capitals and add the dash after every four characters; pasting works with or without the dash. A parent's code, a staff invitation and a recovery link are now spent only once the passkey is made, so cancelling or failing the passkey step and trying again works instead of saying the code has expired. Each one still works only once.
Where: Sign in, then "Got a code from your parent?" or "App reviewer? Sign in with a code".
Try: Type a parent's code in small letters without the dash. Then cancel the passkey prompt and try the same code again.
