What's next now lists things in the order the church office put them, the same as the email.

## For staff
Changed: The app sorted the digest into weeks by date (This week, Next week…), so things could appear in a different order from the running order and the email. It now follows the running order exactly, with no week headings; each thing still shows its own date.
Where: The app → What's next, and the In the app preview in Admin panel → Weekly digest.
Try: Drag an item lower in the running order and check the preview and the app follow it.
