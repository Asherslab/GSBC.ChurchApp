Fonts for themes now live where they belong in Media, and a theme can use a font file the church has.

## For staff
Changed: A Google font chosen for a theme is now kept under Made by the app, in Fonts from Google, instead of in the Library, and the ones already in the Library have moved there. For a font the church has its own file for, upload the file to Media (.woff2, .woff, .ttf or .otf) and choose it in the theme like a photo.
Where: Admin panel → Drafts → a theme under Colours → a font → Change → Choose a font file from Media. Media → Made by the app → Fonts from Google.
Try: Open Media and look under Made by the app for Fonts from Google. In a theme, choose a font file from Media for the masthead.
