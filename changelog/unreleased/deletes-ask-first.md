Deleting a break or an unsent announcement now asks first.

## For staff
Changed: Deleting a break, an announcement that hasn't been sent, or a role in the advanced role editor used to happen straight away. Each now asks first and says what happens: for a break, which regular events are on again on those dates.
Where: Admin panel → Events → a break → Delete this break. Announcements → an unsent announcement → Delete….
Try: Open a break that a regular event uses, press Delete this break, read what it says, then choose Keep it.
