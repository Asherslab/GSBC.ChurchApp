Events can be changed on the phone even with no signal; the change is sent as soon as the phone is back online.

## For staff
Changed: On the phone, a calendar's editors open and change events, regular events and single dates from what's already on the phone, so it works with no signal. Saving shows "Waiting to send" until it reaches the server, or "Couldn't save" with the reason and Try now. If two people change the same event, each keeps what they changed; if both change the same thing, the later save wins. Picking a picture shows the pictures already on the phone first (these work offline); the whole Media library needs a connection.
Where: The app's calendar: open an event and tap Edit, or a calendar's Regular events.
Try: Turn on flight mode, edit an event's time and save. See "Waiting to send", then turn flight mode off and check the change reaches the admin panel. Add a new event offline and open it.
