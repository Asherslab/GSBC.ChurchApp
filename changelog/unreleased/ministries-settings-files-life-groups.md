Ministries get a few settings leaders asked for, and Life Groups show their Sundays from a linked calendar.

## For staff
Changed: A new ministry starts with only News, Calendar and Chats on. Settings → What it uses has *Who can start a chat*: leaders (as before) or the team too (team members start group chats for the team). A document's *Who it's for* can now be changed like a link's; the stored file moves between public and private for you. The admin panel adds documents from the computer (Files → Add a file). Any ministry can *Link a calendar* for everyone (admin panel, Calendar tab); a Life Group's linked calendar shows only that group's Sundays, and an all-year group follows every set's Sundays and the breaks it sits out. The Sundays tab is gone: its "No class this Sunday" notes are under Calendar → Its Sundays.
Where: A ministry's Settings, Files and Calendar tabs, in the app and the admin panel.
Try: Create a ministry and check What it uses. Set Who can start a chat to the team too and start one as a team member. Change who a document is for. In the admin panel add a PDF to Files, and link the calendar with the Life Groups entry to a Life Group, then check only its Sundays show.
