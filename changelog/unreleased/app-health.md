App errors from phones, the admin panel and the server now show in the admin panel.

## For staff
Changed: A new App health page, for whoever builds the app, lists every kind of error from the last 7 or 30 days: what it was, where in the app, how often, on which versions, and whether it came from a phone, the admin panel or the server. Choose one to see the pages, builds and devices it happened on. Calls to the server that failed are counted below. Whoever can see app errors also gets one email the first time a new kind appears.
Where: The admin panel → The app → App health. Only people with the Developer role (or Owner) have it.
