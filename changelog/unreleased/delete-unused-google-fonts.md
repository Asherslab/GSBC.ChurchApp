A font fetched from Google that no theme uses can be deleted.

## For staff
Changed: Fonts the app fetched from Google for a theme used to stay in Media for ever. One that no theme or draft uses can now be deleted; one in use still can't.
Where: Admin panel → Media → Fonts from Google: choose the font, then Delete….
Try: Choose a Google font in a theme draft, then pick another one and save. Open Fonts from Google and delete the font you stopped using.
