An announcement you're writing says when it can't save yet, and asks before you leave it.

## For staff
Changed: An announcement saves as you type, but it can't save without a title (or while what it opens isn't chosen). It used to say "Saved" anyway, and leaving lost what you'd written. It now says "Give it a title so it can save", and leaving the desk while it can't save, is still saving or couldn't save asks first.
Where: Admin panel → Calendar & news → Announcements.
Try: Start a new announcement, write a message without a title and click another page. Choose Stay, add a title, and check it says "Saved".
