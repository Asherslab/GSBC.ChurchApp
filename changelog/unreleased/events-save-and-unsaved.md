title: Event editors save when you've typed a title, and keep your changes
audience: everyone
added: 2026-11-10
icon: calendar
area: Calendar
---
Adding a regular event works again as soon as it has a title, and the calendar asks before you leave an event with changes you haven't saved.

## For staff
Changed: In a new regular event, *Add the regular event* stayed grey and the header kept saying "New regular event" even after you typed a title. It now updates as you type. Every event editor (one-off events, regular events, a single date, a calendar's settings and a break) shows why it can't save yet ("Give it a title to add it."), "You have changes that aren't saved" beside the button, and "Saved" once it has. Switching to another event, calendar or break, going back, or leaving the page with unsaved changes asks: save, discard them, or stay. A calendar's settings and a break no longer lose what you typed when the calendar refreshes. The digest saves by itself as before, and only asks if you leave while it is still saving or couldn't save.
Where: Calendar in the admin panel; an event's Edit in the app.
Try: Calendar → New event → Regularly. Type a title and check the header and button update. Then click another event and choose Stay, then Save and go on.
