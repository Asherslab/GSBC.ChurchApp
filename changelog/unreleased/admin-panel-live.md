What you see in the admin panel updates by itself when someone else changes it.

## For staff
Changed: Pages in the admin panel update within a second or two when anyone changes what they show: a draft someone else is editing, a publish, a new picture in Media, a role given or taken away, a new person. If someone changes the row you're typing in, your typing is kept and you can choose to see their version instead.
Where: Every page of the admin panel, on a computer.
