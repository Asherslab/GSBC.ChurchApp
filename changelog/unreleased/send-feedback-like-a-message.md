Sending feedback from the phone is now like writing a message, and stays small with the keyboard up.

## For staff
Changed: Send feedback has the usual top bar instead of a big heading, a short line about what's sent with it, and a message box docked at the foot: the paperclip adds screenshots or videos (they show as small thumbnails above the box) and the round button sends. With the keyboard up, what you're writing and Send stay in view. Chats' message box is the same box now, and both drop the keyboard's ^ v ✓ bar so they sit right on the keys.
Where: More, then tap the church mark at the foot three times.
Try: Open Send feedback, start typing so the keyboard comes up, add a screenshot with the paperclip, then send. Then open a chat and start a message.
