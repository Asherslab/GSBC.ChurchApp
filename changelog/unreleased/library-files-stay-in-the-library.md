Using a Library picture or file in a news post no longer moves it out of your folders.

## For staff
Changed: A picture or file you choose from the Library for a church or ministry news post stays in its Library folder; only files uploaded straight into a post go to Made by the app. Library files a post had already moved into Made by the app (Church news or Ministry posts) come back to the top of the Library; drag them into the folder you want. In the post editor, the line under each picture or file shows where it is in Media (for example "~/Main Images/letterboxing.jpeg") every time you open the post, not only just after choosing it. The Church news and Sermon artwork notes in Made by the app now say plainly that you can delete files nothing uses any more.
Where: Media → Library, and News → a post's editor in the admin panel.
Try: Put a picture from a Library folder in a news post and save it, then open Media: the picture is still in its folder and shows "Used in 1 place".
