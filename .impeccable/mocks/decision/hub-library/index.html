17. Renaming or taking a tile out of the library

Today it's only in the settings panel when no tile is chosen, and opens the saved tile's raw fields. People meet the library in Add a tile.

Chosen
A · MANAGE

A Manage button beside "Your library"

Like Edit on an iPhone list. Manage turns each saved tile into its name field and a Take out button; Done goes back. A tile taken out leaves a line with Undo until the sheet closes. The same list, same Manage, is in the panel when no tile is chosen, so there's one way to do it.

18–19. Saving: one tile per name, and a name of its own

Save to the library made a new saved tile every time, named after the tile's title. Names must be unique (ignoring case and spaces at the ends), and the library name is separate from the title the app shows.

Chosen
A · ONE SAVE SHEET

Save opens a small sheet with the name

"Name in the library", filled with the tile's title; only staff see it. If the name is free: Save. If it's taken, a plain warning and the buttons become Replace "Ministries" and Save as a new name (which fills in "Ministries 2" for you to adjust), plus Cancel. The server refuses a clash too.
